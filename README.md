# 3D-Spiele erklärt – Von Punkten zu Pixeln

Ein Erklärbuch zum Selbstlernen für den Informatikunterricht der 11. Klasse (etwa 90 Minuten): Welche Datenstrukturen und Algorithmen stecken hinter einem 3D-Spiel, und wie hoch ist ihr Aufwand?

Kapitel: Einstieg (Zeitbudget) · Koordinaten · Figuren aus Dreiecken · Kollisionen · Kamera und Pixel · Licht und Schatten · Geschichte · Die Spielwelt

Voraussetzungen: Python-Grundlagen (Listen, Schleifen, Funktionen), Pythagoras, Strahlensatz, Sinus und Kosinus.

## Technik

Reines HTML, CSS und JavaScript, ohne Build-Schritt und ohne externe Dienste. Die Schriften Fraunces und Figtree (beide SIL Open Font License) liegen im Ordner `fonts`. Die Demos nutzen die kleine Bibliothek `js/mini3d.js`.

Die Bilder der Ritterin wurden mit KI erzeugt.
