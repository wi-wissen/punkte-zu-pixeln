Licht und Schatten

Ohne Licht wäre jedes Dreieck einfarbig und die Szene flach. Es gibt zwei grundverschiedene Wege, Licht zu berechnen, und sie unterscheiden sich vor allem im Aufwand.

Weg 1: Helligkeit aus dem Winkel

Eine Fläche ist am hellsten, wenn das Licht senkrecht auf sie trifft, und dunkel, wenn es sie nur streift. Um das zu berechnen, braucht man zwei Richtungen als Vektoren der Länge 1: die Normale n, die senkrecht auf der Fläche steht, und die Richtung l zur Lichtquelle. Die Helligkeit ist der Kosinus des Winkels zwischen beiden. Für Vektoren der Länge 1 ist das gerade ihr Skalarprodukt:

def helligkeit(n, l):
    k = n[0]*l[0] + n[1]*l[1] + n[2]*l[2]     # cos des Winkels zwischen n und l
    return max(0, k)                          # von hinten beleuchtet: dunkel

Das sind drei Multiplikationen pro Pixel, also praktisch umsonst. Die Rechnung betrachtet aber nur die Fläche selbst und die Lichtquelle. Ob ein anderes Objekt dazwischen steht, weiß sie nicht. Schatten entstehen so nicht.

Weg 2: Raytracing

Raytracing dreht die Rasterisierung um. Statt zu fragen, welche Pixel ein Dreieck bedeckt, fragt man für jedes Pixel, was dort zu sehen ist. Dazu wird von der Kamera aus ein Strahl durch das Pixel in die Szene verfolgt. Am ersten Treffer wird ein zweiter Strahl zur Lichtquelle geschickt. Trifft dieser Schattenstrahl unterwegs ein Objekt, liegt der Punkt im Schatten.

for pixel in bild:
    strahl = strahl_durch(kamera, pixel)
    treffer = naechster_schnittpunkt(strahl, szene)
    if treffer is None:
        pixel.farbe = HIMMEL
    else:
        zum_licht = strahl_von(treffer.punkt, lichtquelle)
        if naechster_schnittpunkt(zum_licht, szene) is not None:
            pixel.farbe = SCHATTEN
        else:
            pixel.farbe = treffer.farbe * helligkeit(treffer.normale, zum_licht.richtung)

Der Schnitt von Strahl und Kugel

Ein Strahl startet im Punkt o und läuft in Richtung d. Jeder Punkt auf ihm ist o + t · d mit t ≥ 0. Eine Kugel mit Mittelpunkt m und Radius r besteht aus allen Punkten mit Abstand r von m. Setzt man den Strahl in die Abstandsformel aus Kapitel 1 ein, entsteht eine quadratische Gleichung für t:

t² + 2·b·t + c = 0

mit b = (o − m) · d und c = (o − m) · (o − m) − r², wobei der Punkt das Skalarprodukt meint und d die Länge 1 hat. Die Lösungsformel liefert t = −b ± √(b² − c). Ist der Ausdruck unter der Wurzel negativ, verfehlt der Strahl die Kugel. Sonst ist die kleinere positive Lösung der vordere Schnittpunkt.

def schnitt_kugel(o, d, m, r):
    om = [o[0] - m[0], o[1] - m[1], o[2] - m[2]]
    b = om[0]*d[0] + om[1]*d[1] + om[2]*d[2]
    c = om[0]*om[0] + om[1]*om[1] + om[2]*om[2] - r*r
    diskriminante = b*b - c
    if diskriminante < 0:
        return None                      # kein Schnittpunkt
    t = -b - diskriminante ** 0.5
    return t if t > 0 else None

Aufwand

Die einfache Fassung testet jeden Strahl gegen jedes Objekt. Bei 2 Millionen Pixeln und 1 Million Dreiecken wären das 2 Billionen Schnitttests pro Bild, dazu noch einmal so viele für die Schattenstrahlen. Das ist aussichtslos.

Die Rettung kennst du aus Kapitel 3: Hüllkörper. Man fasst nahe beieinanderliegende Dreiecke in Quadern zusammen, diese wieder in größeren Quadern, bis ein Baum entsteht. Verfehlt ein Strahl einen Quader, entfallen alle Dreiecke darin auf einen Schlag. Statt n Tests braucht ein Strahl dann nur noch etwa log₂ n. Bei einer Million Dreiecken sind das rund 20 Schritte statt einer Million.

Die Rasterisierung erzeugt Schatten mit einem Umweg: Die Szene wird zusätzlich aus Sicht der Lichtquelle gezeichnet. Der Tiefenpuffer dieses Bildes verrät, welche Punkte das Licht sieht. Alle anderen liegen im Schatten.

Heutige Spiele kombinieren beides. Das Grundbild entsteht durch Rasterisierung. Raytracing kommt gezielt hinzu, etwa für weiche Schatten und Spiegelungen, oft mit nur einem Strahl pro Pixel.

Merke: Die Helligkeit einer Fläche ist das Skalarprodukt aus Normale und Lichtrichtung. Raytracing verfolgt pro Pixel einen Strahl von der Kamera und einen Schattenstrahl zum Licht. Der Schnitt mit einer Kugel ist eine quadratische Gleichung. Bezahlbar wird es erst durch einen Baum aus Hüllkörpern.

Aufgabe: Eine Szene hat 8 Millionen Dreiecke. Wie viele Schritte braucht ein Strahl ungefähr im Baum aus Hüllkörpern, wenn jede Ebene die Zahl der Dreiecke halbiert?
Lösung anzeigen
log₂(8 000 000) ≈ 23, denn 2²³ = 8 388 608. Statt 8 Millionen Tests genügen also etwa 23 Schritte bis zu einem einzelnen Dreieck.
Aufgabe: Warum genügt für den Schattenstrahl die Antwort „irgendein Schnittpunkt“, während der Kamerastrahl den nächsten Schnittpunkt braucht?
Lösung anzeigen
Für den Schatten zählt nur, ob etwas im Weg steht. Die Suche kann beim ersten gefundenen Hindernis abbrechen. Der Kamerastrahl muss wissen, welches Objekt vorn liegt, also das kleinste t finden.
